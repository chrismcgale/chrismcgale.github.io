01 / FLAGSHIP · PUBLISHED · IEEE ICMA

Submersivity: submarine → AI → AR pipeline

An ESP-DIVE-based ESP32-S3 submersible with a 3D-printed hull surveys Peter Street Basin; fine-tuned YOLOv8s flags garbage (mAP50 0.883), COLMAP + ArUco place every detection in a mapped model of the basin, and Vuzix Smart Swim XR goggles guide the cleanup diver to the nearest target. Built in Steve Mann's lab.

PUBLISHED ESP32 YOLOv8 ArUco COLMAP Vuzix AR
02 / ACTIVE RESEARCH

Rinnegan: GPS-denied cooperative perception

N agents run Kimera-VIO; inter-agent loop closures and robust pose-graph optimization (GTSAM) estimate a shared frame peer-to-peer, without GPS or a central server. This lets one agent's detections be rendered in another agent's view, including through walls, at 0.6 px / 0.07 m error, with a CUDA TSDF HUD at 43 FPS. Target: a 7-inch 6S FPV quad.

ACTIVE DEV C++ / CUDA Kimera-VIO GTSAM ROS 2 Isaac Sim
03 / HARDWARE · CUSTOM FLIGHT CONTROLLER

Rook: custom STM32H743 flight controller

A flight controller of my own design: a 4-layer STM32H743 board for a 7-inch 6S quad, laid out pin-for-pin compatible with Betaflight and ArduPilot so both firmware stacks can run on it with minimal porting. Reverse-poly protected 6S power tree, ICM-42688-P gyro on a dedicated low-noise LDO, whole schematic generated from code. Board routed, DRC-clean, pre-fab.

ROUTED · PRE-FAB STM32H743 ICM-42688-P KiCad Betaflight ArduPilot
